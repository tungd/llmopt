# Audit result

The canonical cleanup removed the Q8-weight and selectable-FP16-KV executable
paths, but it also replaced the 5,894-line regression suite with a narrow
canonical smoke test and left the new W4 FFN rule as discovery-only. The
format-independent generation, tokenizer, decode replay, serving queue,
schedule, and compiler-fusion checks are active again. The canonical package
audit tool is also restored without its former hard-coded Q8 paths or synthetic
command threshold.

Q8-weight IR variants, kernels, bridges, and Python differentials remain
retired. Their useful optimization ideas are ports, not code paths to restore.
This slice ports the complete FFN family; paired-SIMD W4 GEMV, QKV/RoPE,
residual-norm, attention-block, and whole ShortConv-block ports remain open.

# Rule and lowering

`Fusion_query.Rule` now owns emission and rewriting. It rejects overlapping
matches, rejects intermediate values consumed outside the matched region, and
requires the lowering to use external inputs. `Pass_fuse_swiglu_ffn` uses that
single rule to recognize RMSNorm, gate W4 linear, SiLU, up W4 linear, multiply,
down W4 linear, and residual add, then emits one typed
`W4a16_swiglu_ffn` operation with the original output identity.

The captured model crosses FP32 into RMSNorm, then uses FP16 normalized
activations and residuals around packed uint4 group-64 weights. The runtime
therefore dispatches three stages: cooperative RMSNorm, one parallel gate/up
projection that writes the SwiGLU product, and one parallel down projection
that adds the residual. An initial single-threadgroup implementation preserved
the graph reduction but measured median TPOT `28.9046493 ms`; it was replaced
because it serialized output channels and underused the GPU.
