# Result

G4P12-04a (commit `b5ee732`) is the first commit-sized sub-slice of G4P12-04 (emission widening, per the LOOP split at `0d556e7`). It makes `Metal_block_codegen` able to emit digest-shaped epilogue kernels structurally, so the legacy `Metal.q4_0_x8_digest_*` text splice can be deleted in 04b with a byte-identity oracle in place.

1. **Parametric epilogue tail.** `emit_q4_0_linear_f16_x8` (lib/metal_block_codegen.ml:584) now takes `?(split_k = 1) ?(name = "llmopt_q4_0_linear_f16_x8") ?(epilogue = Epilogue.none)`. The `None` default reproduces today's flat `llmopt_q4_0_linear_f16_x8` kernel byte-for-byte (split_k=1) or the split_k=2 flat text. A canonicalized non-`None` epilogue with split_k=1 emits the digest variant; any other combination is a loud `invalid_arg`.
2. **Structural digest emission.** `q4_0_x8_digest_of_flat ~name epilogue kernel` (:537) is a line-for-line port of `Metal`'s `q4_0_x8_digest_store`/`q4_0_x8_digest_rewrite`: it rebuilds the header to `input [[buffer(0)]]`, `weight [[buffer(1)]]`, `Epilogue.msl_buffer_decls ~start_index:2`, `output [[buffer(2+p)]]`, `params [[buffer(3+p)]]` with the thread-position attributes preserved, and rewrites the store tail into eight guarded `Epilogue.emit_msl_writeback` stores. The schema-level `q4_0_x8_epilogue_kernel` (:2184, exported in the .mli) validates Q4_0/4-bit/block32-SIMD32, builds the flat text via the parametric emitter, and runs it through the digest rewrite; the caller passes a canonicalized epilogue.
3. **Golden capture.** Before the splice is deleted, three digest kernels were captured from the legacy splice output and frozen as fixtures: `test/golden/q4_0_x8_digest_gemma_chain.msl`, `..._f32_expr.msl`, `..._silu.msl`. §5 of `test/test_epilogue_monoid.ml` now asserts byte-identity between the structural emitter output, the still-present legacy `Metal.emit_q4_0_x8_epilogue_kernel`, and each fixture (exactly one capture newline stripped) for the gemma_chain composite, an f32 expression, and the bare silu epilogue.
4. **First Epilogue dependency.** `Metal_block_codegen`'s ninja edges gain `_build/ocaml/epilogue.cmi/.cmx` (plus the test edge pulls `target_hardware`, `block_schema`, and `metal_block_codegen` into `test_epilogue_monoid.cmx`).

New test line: `[PASS] Structural Q4_0 x8 epilogue-tail emission is byte-identical to the golden digest kernels`, followed by the pre-existing §5 decode-base pins, unchanged.
