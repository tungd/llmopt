# Result

G4P12-04c-3 (commit `357fab9`) closes the per-tile 04c admission widening with the Q4_0 m32 decode tile (m ≥ 32): the tile kernel runs **two** simdgroups per 32-row tile — `simd_idx >> 1` picks the tile, `simd_idx & 1` picks the sixteen-row half starting at `sub_row_base = row_base + (simd_in_tile << 4u)`. Each simdgroup therefore keeps its own `float acc[16]`, and the digest writeback is structurally the same sixteen guarded stores as m16 but guarded against `sub_row_base`. The flat m32 default stays byte-identical and every unservable shape stays loud.

1. **m32 digest-of-flat is the m16 machinery over a new row-guard variable.** `lib/metal_block_codegen.ml` defines `q4_0_m32_digest_of_flat` as `q4_0_row_block_digest_of_flat ~rows:16 ~row_guard:"sub_row_base" ~label:"m32"`. Note the decisive correction to the plan sketched in exp-0161: `rows` is **16, not 32**, because a single m32 simdgroup computes only sixteen accumulator slots (its half of the tile); the second simdgroup covers the other half through its own `sub_row_base`. The 32-row coverage comes from the **grid** (two simdgroups per tile), not from a wider per-simdgroup store loop.
2. **m32 emitter + schema-level entry.** `emit_q4_0_linear_f16_m32 ?(name = "llmopt_q4_0_linear_f16_m32") ?(epilogue = Epilogue.none) ~scale_offset ... ~block_bytes ()` keeps the None default byte-identical to the flat kernel (template wrapped as `let flat = ...`, argument list unchanged, concat call site (:2306) gains the now-required `()`); a canonicalized non-None epilogue routes into `q4_0_m32_digest_of_flat`. The exported `Metal_block_codegen.q4_0_m32_epilogue_kernel ~name ~epilogue ~target schema` (mli + wrapper after `q4_0_m16_epilogue_kernel`) validates the Q4_0/4-bit schema and is the lower admission point.
3. **Lower admission widened.** `Metal.lower`'s digest fold picks `q4_0_m32_epilogue_kernel` for `_m32` tactic bases next to `_x8`/`_x4`/`_m16`; the loud error text for every other (quant × tile) combination now names the x8/x4/m16/m32 regions. As with m16, no `quant_add_twin_servable` change was needed — the `_m32_add` zoo twin is legacy noise retired by 04d.
4. **Runtime key + grid widened.** `metal_runtime.ml`'s digest dispatch adds the `_m32` branch `digest_columns = Some (((linear.m + 31) / 32) * linear.n * 2)` — the ×2 doubling is exactly the two-simdgroups-per-tile fact from item 1, so the digest grid launches `(m_tiles × n × 2)` simdgroups. Comments and the loud error text are updated to x8/x4/m16/m32.
5. **Pins.** §5 of `test/test_epilogue_monoid.ml` proves m32 structural emission: digest rename, zero-buffer layout (output buffer(2)/params buffer(3), no `buf_` decls for the None default), sixteen sub-row-guarded stores with `if (sub_row_base + 15u < params.m) {` and `const uint out_idx15 = (sub_row_base + 15u) * params.n + column;`, exactly 16 `output[` occurrences, and deterministic re-emission. `test.ml`'s full-stack proof lowers a `[32; 3840]` Q4_0 y*y graph (Linear m=32 n=4096 k=3840, output squared) to one two-binding `Linear_epilogue` region and checks plain + digest registration, the digest text (negative bias/`has_bias` checks scoped to the digest kernel slice via the m16 helper reuse), and the Linear/Q4_0/Float16 ABI entry with threadgroup (256,1,1). The 04c-2 proof-writing lessons carried over unchanged: pick the digest ABI entry excluding `_add` names and scope negative checks to the digest kernel slice. Marker: `llmopt Q4_0 m32 digest emission and lower admission passed`.
