# Result

G4P12-04c-2 (commit `0cbaacb`) opens the batched-row half of the 04c admission widening with the Q4_0 m16 decode tile (16 ≤ m < 32): the tile kernel runs one simdgroup per (row tile × column) with a `float acc[16]` register array, so the digest writeback is no longer a single-row column span but one guarded store per accumulator row. The flat m16 default stays byte-identical and every unservable shape stays loud.

1. **Row-block digest machinery.** `lib/metal_block_codegen.ml` adds `q4_0_row_block_epilogue_stores ~rows ~row_guard epilogue` and `q4_0_row_block_digest_of_flat ~rows ~row_guard ~label ~name epilogue kernel` (:508-580), the multi-row counterpart of the 04c-1 single-row form. The digest header layout matches exactly (epilogue buffers at buffer(2..2+p), output at buffer(2+p), params at buffer(3+p), attributes preserved from `uint gid [[thread_position_in_grid]],`); the flat tail (`  if (lane == 0u) {`) is replaced by one guarded store per row r: `if (row_guard + r < params.m) { const uint out_idx{r} = (row_guard + r) * params.n + column; output[out_idx{r}] = half(EXPR); }` with EXPR from `Epilogue.emit_msl_writeback ~acc:("acc[" ^ string_of_int r ^ "]") ~idx:("out_idx" ^ string_of_int r)`. A `%du` vs `%d` discipline is required: the row-guard arithmetic literal uses `%du`, the C identifier digits use `%d` (a `%du` identifier would glue the `u` suffix into the variable name and break the writeback index reference). `q4_0_m16_digest_of_flat` is the `~rows:16 ~row_guard:"row_base"` instantiation; the same helper later serves m32 over `sub_row_base`.
2. **m16 emitter + schema-level entry.** `emit_q4_0_linear_f16_m16 ?(name = "llmopt_q4_0_linear_f16_m16") ?(epilogue = Epilogue.none) ... ()` keeps the None default byte-identical to the flat kernel (template wrapped as `let flat = ...` with the argument list unchanged); a canonicalized non-None epilogue routes into the digest variant. The exported `Metal_block_codegen.q4_0_m16_epilogue_kernel ~name ~epilogue ~target schema` (mli + :2359) validates the Q4_0/4-bit schema and is the lower admission point alongside the 04a/04c-1 x8/x4 emitters. The flat-zoo concat call site (:2286) gains the now-required `()`.
3. **Lower admission widened.** `Metal.lower`'s digest fold (lib/metal.ml :10856+) picks `q4_0_m16_epilogue_kernel` for `_m16` tactic bases next to `_x8`/`_x4`; the loud error text for every other (quant × tile) combination now names the x8/x4/m16 regions. No `quant_add_twin_servable` change was needed: the m16 y*y region already routes through the digest fold — the digest-keyed `llmopt_q4_0_linear_f16_m16_62bdb36d` kernel was emitted and registered in the very first diagnostic run. The still-registered `llmopt_q4_0_linear_f16_m16_add` entry is legacy static-zoo noise, not a routing defect: unlike `x8_add`/`x4_add` (which never existed as static kernels), the Q4_0 family text embeds `m4_add`/`m16_add`/`m32_add` twins for every Q4_0 program regardless of the actual epilogue. Retiring those twins is 04d's job.
4. **Runtime key + grid widened.** `metal_runtime.ml`'s digest dispatch computes `digest_columns = Some (((linear.m + 15) / 16) * linear.n)` for `_m16` (alongside `(n+7)/8` x8 and `(n+3)/4` x4), with the digest grid over those columns; comments and the loud error text are updated to x8/x4/m16.
5. **Pins.** §5 of `test/test_epilogue_monoid.ml` proves m16 structural emission: the digest kernel carries the digest name and the zero-buffer layout (output at buffer(2), params at buffer(3), no `buf_` decls), 16 row-guarded stores with `if (row_base + 15u < params.m) {` and `const uint out_idx15 = (row_base + 15u) * params.n + column;`, exactly 16 `output[` occurrences, and deterministic re-emission; the flat default keeps `kernel void llmopt_q4_0_linear_f16_m16(` with no epilogue buffers. `test.ml`'s full-stack proof lowers a `[16; 3840]` Q4_0 y*y graph (Linear m=16 n=4096 k=3840, output squared) to one two-binding `Linear_epilogue` region and checks plain + digest registration, the digest text, and the Linear/Q4_0/Float16 ABI entry with threadgroup (256,1,1). Proof-writing lessons that 04c-3 should reuse: (a) pick the digest ABI entry with `contains "_m16_" && not (contains "_add")` because registration order lists the `_m16_add` zoo twin before the digest kernel, so `List.find_opt` on the bare suffix finds the wrong kernel; (b) scope negative bias/`has_bias` checks to the digest kernel slice (header through its first column-0 `}\n`), because the program source still embeds the whole legacy Q4_0 zoo with its bias slots. Marker: `llmopt Q4_0 m16 digest emission and lower admission passed`.
