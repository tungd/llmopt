Compiler/runtime change
-----------------------

`Serving_schedule.Lfm25.specialize_decode` replaces every captured
`[1;1;1;64]` cosine/sine input with canonical runtime values
`__llmopt_rope_cosine` and `__llmopt_rope_sine`, then liveness-prunes the
captured scalar position/trigonometric branch. `Serving_engine.Rope_table`
reads the archived float32 inverse frequencies at engine load, computes all
128,000 LFM2 position rows in float32, stores the duplicated half-dimension
values as FP16, and binds one row per decode position. Replay uses independent
row views; ordinary decode uses fixed slots copied from the selected row.
