Architectural verification
--------------------------

1. Barrier-Free Streaming Decode GEMV: Parameterized quantized linear codegen in lib/metal_block_codegen.ml eliminates threadgroup barriers and threadgroup shared memory staging (s_activation[4096]). Activations stream directly from device memory through M4 Pro L1/L2 cache with SIMD-group cross-lane reduction (simd_sum), cutting decode execution overhead.
2. Ping-Pong Double-Buffered Asynchronous Queue: Double-buffered token input and output buffers in native/ocaml_metal_stubs.m isolate alternating dispatch slots, eliminating host/device data races.
3. Prefill Schedule Caching & Warmup: Serving engine pre-caches prompt prefill execution schedules during warmup, reducing prompt evaluation latency and TTFT.
4. Parity Invariant: 128/128 completion tokens strictly match the pinned golden reference sequence.
